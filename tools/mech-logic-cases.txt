Planted.

# The day-one Restitution bug: restitution by itself closes the debt.
If a restitution is a restitution by an agent to a second agent for an act, and the moral debt of the first agent to the second agent from the act exists, then the moral debt of the first agent to the second agent from the act is closed.

# The Circumstances bug: circumstances supply a consent no channel carried.
If the circumstances fix the meaning of an act as consent by an agent, then the first agent consented to the act.
