Planted.

# The day-one Restitution bug: restitution by itself closes the debt.
If a restitution is a restitution by an agent to a second agent for an act, and the moral debt of the first agent to the second agent from the act exists, then the moral debt of the first agent to the second agent from the act is closed.

# The Circumstances bug: circumstances supply a consent no channel carried.
If the circumstances fix the meaning of an act as consent by an agent, then the first agent consented to the act.

# The implicit-theft bug: inability itself becomes a crossing (the debtor
# who cannot pay is branded a thief).
If an act is the failure of a transfer from an agent, and the transfer is a conditional transfer from the first agent to a second agent, then the act is an act of the first agent crossing the property boundary of the second agent.

# The sovereignty bug: an agent who is not the victim closes the debt.
If the moral debt of an agent to a second agent from an act exists, and a third agent releases the debt from the act, then the moral debt of the first agent to the second agent from the act is closed.

# The juristic bug: a judgment makes guilt.
If an act is a judgment that an agent caused the harm of a second act to a second agent, then the moral debt of the first agent to the second agent from the second act exists.

# The Locke bug: making a thing confers ownership.
If an agent makes a thing at an act, then the thing is the property of the first agent.

# The statist bug: a commanded transfer is a debt.
If a transfer is commanded by authority on an agent for a second agent, then the transfer is a conditional transfer from the first agent to the second agent.

# The collective bug: a member owes for the crime of the group.
If an act is a crime by an agent with victim a second agent, and a third agent is part of the group of the first agent, then the moral debt of the third agent to the second agent from the act exists.
